# AXIOM Architecture — Public Interface

This directory describes public contractual boundaries for AXIOM's modular
human–machine architecture. It is deliberately limited to disclosure-safe
interfaces and invariants.

- [Public architecture contract](ARCHITECTURE.md)
- [Validation status](STATUS.md)
- [Version](VERSION) and [changelog](CHANGELOG.md)
- [Schemas](schemas/) and [validation tools](tests/)
- [Publication standard](../PUBLICATION.md)

The 33 stable `INV-001`–`INV-033` identities remain visible for public
reference and automated consistency checks. Internal orchestration algorithms,
provider/account configurations, detailed composition graphs, and unpublished
operational research remain restricted.

Canonical implementation claims must be checked against their owning system
revisions and accepted evidence; the public contract is not a deployment claim.
