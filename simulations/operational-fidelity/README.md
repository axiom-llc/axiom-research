# Operational fidelity

Item 20 extends organizational simulations from representative workflow slices to reconstructable operations.

`operational-fidelity-v1` records actors, resources, schedules, queues, decisions, communications, synthetic financial transactions, inventory movements, documents, events, situations, issues, approvals, state transitions, outcomes, and a causal operation ledger.

Completeness is evidence-scoped, not universal: a run passes only when every material component declared by its modeled operating scope is represented and the reconstruction audit resolves every reference and reproduces expected aggregates. Synthetic amounts are simulated business state and never authorize real spending.
