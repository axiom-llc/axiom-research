# High-fidelity software operating day

This synthetic operating day expands the representative software-delivery scenario into reconstructable operational state: work queues, schedules, engineering/review/security/release authority, communications, CI events, issues and recovery, artifact movements, documents, state transitions, and synthetic labor/compute costs.

`execute.py` delegates to the shared Research operational-fidelity executor. Consequential external effects remain local-file simulations only.
