# Research native RSI

`python -m rsi.native` generates a revision-bound unified-diff candidate without altering source. The sole registered rule replaces `REQUIRED - set(item)` with `REQUIRED.difference(item)` in the research queue validator; set difference semantics remain identical for dictionary keys. Canonical queue validation runs unchanged. Synthetic 300-record fixture and invalid-record holdout test before/after semantics and 11 paired performance samples. CI checks Git apply/reverse restoration. The machine measurement is not production ROI. No candidate patch, change to the actual queue, outbound research, schedule, or deployment is applied. Acceptance/promotion remains separate and requires independently verified positive net benefit, full regression and head-bound CI and revert evidence.
