# Architecture validation status — public edition

The public repository provides deterministic schema checks, fixture validation,
version/change coupling, path integrity checks, and synthetic demonstrations.

Run:
```bash
python3 architecture/tests/check.py
```

Actual build and acceptance evidence are revision-bound. Public schema and
simulation checks do not establish production deployment, independent network
isolation, unrestricted autonomous authority, or customer results.

Implementation-specific status registers, constraints, and unpublicized
engineering observations are retained in private source preservation.
This file contains no operational account state or sensitive security findings.
